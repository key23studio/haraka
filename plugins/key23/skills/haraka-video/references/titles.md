# Title designs

KEY23's own title designs: each always looks finished, in any frame. Use one as an element:

```json
{ "type": "title", "name": "Offer", "design": "t-box", "start": 1, "end": 5, "texts": ["عرض خاص", "خصم 30% على كل الوجبات"] }
```

`texts` fills the design's places for words, in the order below. Keep each about as long as the words it replaces (the design is sized for them). A place you leave out keeps its words, so give every place. Colours follow the plan's `theme` (`accent`, `text`). A title takes only `type`, `name`, `design`, `start`, `end`, `texts`.
